# P32 — 工作流面板渐进式展示

## 背景

用户反馈右栏工作流面板一次性展示阶段、任务、Assignment、Mailbox、结构化结果等信息，信息密度过高，容易让普通用户懵。

## 调整原则

- 默认面板只回答三个问题：
  1. 现在谁在干活？
  2. 当前到第几步？
  3. 当前任务是什么？
- 高级信息不删除，但放入默认折叠的「高级详情」。
- 保留原有调试/验收能力：任务状态修正、失败任务快捷处理、Assignment、Mailbox、结构化结果。

## 本轮修改

- `GroupChatHudWorkflowPanel` 默认展示：
  - 执行导演台；
  - 执行中 / 待处理 / 邮箱三项数字；
  - 当前阶段卡片；
  - 当前任务卡片；
  - 等待审批时的「批准」动作。
- 新增默认折叠「高级详情」：
  - 阶段流程；
  - 任务明细；
  - 工具归口 chips；
  - 最近任务分派 / Assignment；
  - 主 Agent 邮箱 / Mailbox；
  - 结构化结果与失败任务快捷处理。

## 验收

- 默认可视信息更少，降低理解成本。
- 高级调试能力仍保留，不影响已有测试。
- 右栏防溢出策略继续生效。
