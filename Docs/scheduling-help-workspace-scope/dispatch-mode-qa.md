# 调度模式 QA 与工作区隔离说明

## 调度模式怎么选

- **仅 @ 角色**：你明确 `@某角色`，该角色才发言；不 @ 时只记录消息，不触发模型。适合精准点名。
- **工作流**：按右侧五阶段推进；当前阶段责任人执行，阶段产物由总指挥审核后进入下一阶段。适合完整研发/交付任务。
- **主持人调度**：每条人类消息先给总指挥，总指挥拆解后安排角色。适合你不想手动点名但需要有人控场。
- **自由讨论**：所有角色都收到主题并自行判断相关度；无关角色返回 `NO_REPLY` 并被静默。适合头脑风暴，调用量更多。

## 配置隔离

插件配置按当前 DSH 工作区保存：

- 房间/角色/主题/调度状态：`.pm-workflow/dsh-group-chat/rooms.json`
- 角色主模型、回退模型、最近模型：`.pm-workflow/dsh-group-chat/model-settings.json`

不会写入宿主全局模型配置；换工作区时，不会复用本工作区角色修改，除非手动复制 `.pm-workflow/dsh-group-chat/`。
