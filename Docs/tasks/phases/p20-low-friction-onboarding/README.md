# P20 — 低理解成本体验

目标：让用户第一次进入 `Agent 群聊` 时不用先理解一堆角色、模式和术语，也能把项目任务丢进去并得到可靠协作。

## 本阶段完成内容

- 中间空态新增 3 步引导：
  1. 说清目标；
  2. 我先排兵；
  3. 你确认后开整。
- 中间空态新增常见项目模板：修 Bug、做 UI、写文档、调研、发布前检查。
- 模板点击后只填入草稿，不直接发送，避免误触发写入或模型调用。
- 右侧调度模式 QA 增加当前上下文：当前模式、适合什么任务、会触发谁、调用量。
- 保持默认：角色主题显示“默认（沙雕整活）”，调度模式显示“默认（工作流）”。

## 交互原则

- 新手优先“说人话”：用户不用懂 commander/subagent，也能先描述任务。
- 写入前确认：自动建角色/工作流只展示草案，确认后才写入当前工作区。
- 调用量可解释：不同调度模式明确告诉用户会触发谁和大概调用成本。
- 趣味但不水：文案轻松，但每句话都服务于任务推进。
