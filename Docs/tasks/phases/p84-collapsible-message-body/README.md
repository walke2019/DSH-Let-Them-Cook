# P84 对话内容折叠显示与默认收起优化规范 (Collapsible Message Body & Default Collapse)

## 一、 背景与痛点
在多 Agent 群聊协同场景中，各角色（如史蒂夫·乔布斯、黄仁勋、雷布斯等）发言通常包含详尽的方案设计、接口定义、代码片段和评审清单，文本跨度大。
原先的群聊界面中：
1. **正文裸露直铺**：对话内容没有折叠能力，长篇大论直接占据数千像素视口，导致用户需要高频上下滑动；
2. **信息层级淹没**：前序发言未收起，导致无法快速纵览全盘讨论脉络；
3. **思考过程粗糙**：原先的思考过程使用原生 `<details>`，缺乏 DSH 原版客户端的折叠指示体验。

## 二、 对齐 DSH 原版与群聊扩展优化方案

结合 DSH 官方客户端（`dsh-client-ui-chat`）的 `DisclosureRow`、`ReasoningRow` 与渐进式披露（Progressive Disclosure）哲学：

1. **长消息判定与自适应折叠**：
   - 超过 140 字符或多于 3 行的内容判定为长消息；
   - **默认收起（Default Collapsed）**：长发言初始收缩为紧凑卡片，带底部自然渐隐蒙层（`linear-gradient mask`）；
   - 短小发言（1~2 行确认、简短指令）直接平展呈现，不产生冗余点击。

2. **精美微交互触发器**：
   - 收起状态时，消息下方展示折叠条 `.gc-collapse-trigger`，展示展开箭头与字数概览（如 `展开全文 · 共 342 字`）；
   - 展开状态时，消息底部操作栏（Actions）提供 `收起` 按钮，随时可恢复精炼卡片；
   - 点击蒙层或展开按钮平滑展开。

3. **全局群聊线程控制条（Thread Toolbar）**：
   - 当消息多于 1 条时，在对话流顶部呈现管理条：
     - 显示发言总数（如 `💬 共 6 条群聊讨论`）；
     - 提供 `全部收起 (Collapse all)` 与 `全部展开 (Expand all)` 按钮，支持一键大纲概览与一键全文阅读。

4. **思考过程与工具调用品质升级**：
   - 升级 `.gc-reasoning-details`，带有专属的大脑图标、首行微缩摘要预览和展开指示箭头，对齐官方原生质感。
