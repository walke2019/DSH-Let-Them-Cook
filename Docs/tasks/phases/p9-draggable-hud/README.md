# P9 — HUD 可拖动浮窗

## 目标

在保留右侧停靠 HUD 的同时，让用户可以把群聊控制台拖成浮动轻窗，避免小屏或窄窗口下遮住中间官方输入区。

## 已完成

- HUD 头部支持拖动，拖动后自动切换为浮窗模式。
- 增加「浮动 / 停靠」按钮，可在浮窗和右侧停靠之间切换。
- 浮窗位置限制在当前视口内，避免拖出屏幕。
- 浮窗高度限制为 `min(720px, calc(100vh - 24px))`，内容继续在 HUD 内部滚动。
- 保持插件式实现，只修改本插件前端，不触碰 DSH 核心源码。

## 验收标准

- 默认仍可通过右侧把手打开 HUD。
- 点击「浮动」后 HUD 变为圆角浮窗。
- 拖动 HUD 头部后，位置随鼠标移动且不会移出屏幕。
- 点击「停靠」后恢复右侧停靠。
