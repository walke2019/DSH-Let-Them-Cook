# P42：Agent 群聊真实入口可用性回归

## 背景

P39/P40 主要保证扩展不会污染官方源版对话。P42 反向验证扩展自身入口是否真正可用：用户从 DSH 官方页面进入承载插件的任务，切到 `Agent 群聊` 后，应能直接看到清爽的中间对话、输入框、引导文案、HUD 四标签和当前工作流概览。

## 验收目标

1. 从 `http://127.0.0.1:3080/` 打开承载扩展的任务。
2. 切到 `Agent 群聊`。
3. 验证中间视图：
   - `.gc-conversation-tab` 存在；
   - `.gc-composer` 存在；
   - 有“把活儿丢进群 / AI 小队开整 / 发送消息”等用户可理解入口文案；
   - 不出现旧标签 `特遣协同` / `特遣监控室`。
4. 验证 HUD：
   - `.dsh-gc-sidebar-host` 存在；
   - 标签为 `团队 / 工作流 / 黑板 / 账本`；
   - 工作流默认信息密度保持清爽；
   - 没有可见横向溢出。
5. 验证浏览器无历史关键错误。

## 维护约束

- 测试必须通过真实浏览器执行，不只做源码字符串检查。
- 若侧栏会话被折叠，脚本需要自动展开其余会话并重新定位任务。
- 用户入口文案允许轻微变化，但必须保留“群聊 / AI 小队 / 发送消息”等低理解成本语义。
