# P37 — 团队页渐进式管理

目标：`团队` 标签承接角色相关管理，但默认态要清爽，避免主题生成、草案、成员编辑入口全部摊开造成认知负担。

## 已完成

- [x] 团队页新增摘要卡：展示主 Agent 与团队人数。
- [x] 团队页新增搜索框，可按角色名、职责、Provider、模型 ID 搜索成员。
- [x] `AI 造主题角色 + 工作流` 改为 `造人/造工作流工具箱` 折叠区，默认收起。
- [x] 成员列表显示匹配数量：`当前匹配/总成员数`。
- [x] 搜索无结果时显示空态，不挤压 HUD。
