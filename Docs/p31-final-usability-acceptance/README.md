# P31 — 最终可用性总验收

## 目标

对当前扩展做阶段性收口：它不只是群聊工具，而是一个面向项目任务的「好玩、低理解成本、可控的多 Agent 协作扩展」。本阶段不继续追加大功能，重点确认核心体验链路稳定。

## 当前完成度

- 官方对话兼容：扩展不覆盖官方 `对话`，单独挂载中间 `Agent 群聊` 标签。
- HUD 定位：右侧为 `shell.overlay` 副屏，标题统一为 `群聊控制台 (HUD)`。
- 布局稳定：HUD 停靠/浮动/拖动/缩放均保持插件作用域，不挤压官方 AppFrame。
- 中间体验：`Agent 群聊` 提供首次三步引导、快捷任务模板、@ 角色入口和清爽对话区。
- 多 Agent 策略：主 Agent 控场，SubAgent 干活；工作流阶段内保留 DSH 并发能力。
- 工具路由：搜索/爬取归调研专员，前后端/QA/文档按职责归口，避免每个 Agent 重复调用工具。
- 主题趣味性：默认沙雕主题，支持原神、现代、三国、传奇，也支持 AI 生成角色+工作流草案并经用户确认后写入。
- 工作区隔离：角色、模型、回退模型、工作流状态保存在当前工作区 `.pm-workflow/dsh-group-chat/`。
- 模型配置：支持最近模型、回退模型、按角色职责推荐模型 ID。
- 文档维护：根目录保持 `README.md` + `AGENTS.md`，阶段文档进入 `Docs/`。

当前收敛 TODO 已完成到 P31，剩余大阶段：**0 个**。
